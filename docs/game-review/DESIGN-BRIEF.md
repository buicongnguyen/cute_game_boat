# Cute Game Boat — Design brief

## 01 Purpose

Build a useful home, prepare for exploration, and return with progress.

Core loop: **grow → prepare → venture → return**. Proposed story: newcomer → confident host.

## 02 Game structure

```text
Game
├─ Home: farming, cooking, storage, companions, decoration
├─ Economy: selling, shops, crafting, materials
├─ Progression: XP, levels, equipment, wishes, beds
├─ Adventure: combat, fishing, travel, gathering, modes
└─ Foundation: controls, saves, language, online
```

## 03 Main checkpoints

Completion rules are current. Attention goals are proposals to verify.

| Steps | Current checkpoint | Player attention goal |
| --- | --- | --- |
| 1 | Harvest 3 crops | Explain the first-hand-harvest gift: Pepper and 10,000 energy. |
| 2–4 | Sell for 20 energy; buy/craft 1 item; equip weapon/disguise | Find cabin services; understand equipment choices. |
| 5–9 | 5 kills; 1 wish; 2 fish; 10 skills; level 5 | Alternate danger, practice, recovery, and quiet play. |
| 10–15 | 25 kills; extra bed; cook 3/harvest 10; 1 boss; 5 fish; level 8 | Show home growth; explain kitchen variants and optional companions. |
| 16–21 | Off-world landing; mine 5; visit 3 worlds; buy/craft 3; place 2 decorations; level 12 | Connect exploration to a visible change at home. |
| 22–28 | 3 bosses; visit 5 worlds; disguise; 150 kills; level 18; visit 9; 10 bosses | Offer variety and stopping points; measure repetition. |
| 29 | Level 25, then claim | Proposed closure and a voluntary next choice. |

Claim each completed step. Active events usually do not backfill; gear ownership can satisfy crafting goals. Visits include home; Night needs level 20. Boss counts need not be unique. Rescues are optional. A locked Normal/Hard kitchen substitutes 10 harvests. Today's tracker continues after 29; the ending and optional tracks remain proposed.

## 04 Checkpoint contract

**Entry → player choice → cue → exit condition → feedback → recovery.**

Check whether players find the next action, understand its result, recover, and stop/resume successfully.

Track: `ID / evidence / change / verification / status`.

## 05 Review priorities

Review one experience problem at a time:

- **UX-001/002:** next-action clarity, claims, and cabin labels.
- **PACE-001:** starter gift versus meaningful spending.
- **GR-005:** waiting, repetition, and useful breaks.
- **STORY-001:** a clear reason to continue.
- **Visuals:** change when an observed readability or control problem requires it.
